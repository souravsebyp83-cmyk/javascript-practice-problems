# JavaScript Practice Problems

Solutions to all 9 questions from the practice sheet.

## Requirements
- Node.js (or a browser console)

## Run
```bash
node solutions.js
```

## Questions covered
1. Print numbers from 1 to 10 using a loop
2. Sum an array of numbers
3. Find the largest number in an array
4. Check whether a number is even or odd
5. Reverse a string
6. Merge arrays with the spread operator
7. Filter even numbers using `filter()`
8. Use a template literal
9. Rewrite a function as an arrow function
